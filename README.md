# Personal Expense Tracker

A beginner-friendly Python CLI project for tracking personal expenses.

## Features

- Add expenses
- View all expenses
- Calculate total spending
- Spending by category
- Find biggest expense
- Filter by category
- Monthly summaries
- Persistent JSON storage
- Input validation and error handling

## Requirements

Python 3.9+

## Run

```bash
python main.py
```

The program automatically creates `expenses.json` when the first expense is saved.

## Example

```text
===== 2026-09 =====
Total spent: ₹2970.00

Shopping        ₹1200.00
Food             ₹850.00
Education        ₹500.00
Travel           ₹420.00

Biggest expense:
₹700.00 - Shoes
```
